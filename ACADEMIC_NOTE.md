# Academic use and attribution

This starter portfolio was independently authored as a learning scaffold. The topic selection was informed by the public reference repository [ARPANPATRA111/mm-lab](https://github.com/ARPANPATRA111/mm-lab).

Do not submit untested code or blank report templates as completed practical work. Run the programs yourself, understand the algorithms, capture genuine outputs, complete the observations in your own words, and follow your instructor's rules. Cite external code, sample media, datasets and documentation that you use.
