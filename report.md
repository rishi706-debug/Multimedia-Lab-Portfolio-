2. Run `python practical-01-image/image_lab.py sample.jpg --out outputs/image`.
3. Inspect the generated files.
4. Record the input image dimensions and compare the output images.

## Algorithm
1. Read the input image.
2. Display format, dimensions, colour mode and file size.
3. Convert a copy to RGB.
4. Generate grayscale, mirror, vertical flip, thumbnail and edge images.
5. Save outputs and inspect them.
